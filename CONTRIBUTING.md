# Contributing

Thanks for improving init-app. Please open an issue for a bug or feature idea,
then submit focused pull requests against `master`.

Set up a development environment with `python scripts/install_dev.py`, run
`python -m pytest`, and update tests and documentation for public CLI changes.
Keep generated files, virtual environments, credentials, and build artifacts
out of commits. By contributing, you agree that your work may be distributed
under this repository's MIT License.
